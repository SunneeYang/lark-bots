## 🧪 测试脚本详解

### 1. deploy.sh - 部署脚本
**功能：** 模拟完整的应用部署流程
**参数：**
- `$1`: 环境（production/staging，默认 production）
- `$2`: 项目目录（默认 /var/www/app）

**输出示例：**
```
===================================
开始部署: deploy
环境: staging
项目目录: /var/www/app-staging
===================================
[1/5] 拉取最新代码...
✓ 代码已更新
[2/5] 安装依赖...
✓ 依赖已安装
...
```

### 2. health_check.sh - 健康检查脚本
**功能：** 检查系统健康状态
**检查项：**
- 磁盘空间使用率（警告阈值：80%）
- 内存使用率
- CPU 负载
- 关键服务状态（nginx, mysql, redis）

### 3. backup.sh - 备份脚本
**功能：** 模拟数据库备份
**参数：**
- `$1`: 备份目录（默认 /var/backups）
- `$2`: 数据库名（默认 myapp）

**特性：**
- 自动创建备份目录
- 生成带时间戳的备份文件
- 自动压缩备份文件

### 4. cleanup_logs.sh - 日志清理脚本
**功能：** 清理过期日志文件
**参数：**
- `$1`: 日志目录（默认 /var/log）
- `$2`: 保留天数（默认 7 天）

**特性：**
- 查找并删除过期日志
- 计算并报告释放的磁盘空间

### 5. test.sh - 简单测试脚本
**功能：** 验证脚本执行基本功能
**特性：**
- 显示参数信息
- 显示执行时间
- 显示系统信息

### 6. fail.sh - 错误场景脚本
**功能：** 模拟脚本执行失败
**特性：**
- 返回非零退出码（exit 1）
- 输出错误信息
- 提供故障排查建议

## 📋 测试配置文件

### configs/bots.test.yaml

**包含 3 个测试机器人：**
1. `test-dispatcher`: 任务分发机器人
2. `test-executor-1`: 执行所有测试脚本
3. `test-executor-2`: 执行部分测试脚本

**安全配置：**
- user_whitelist: 测试用户列表
- task_whitelist: 允许执行的任务列表
- allowed_dispatchers: executor 只接受特定 dispatcher 命令
- allowed_scripts: 只允许执行白名单中的脚本

## 🔐 安全特性

1. **白名单验证**
   - 用户白名单：只有授权用户可以发起任务
   - 任务白名单：只有白名单任务可以执行
   - 脚本白名单：executor 只能执行白名单中的脚本

2. **权限控制**
   - executor 只接受特定 dispatcher 的命令
   - 所有脚本有明确的执行权限控制

3. **安全实践**
   - 脚本使用 `set -e` 遇错即停
   - 输入参数验证
   - 错误信息不泄露敏感数据
